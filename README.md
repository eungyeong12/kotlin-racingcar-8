# 자동차 경주

## 기능 목록

### 1. 자동차 이름을 입력 받는다.

- 쉼표를 기준으로 구분한다.
- 이름이 5자 이하가 아니라면, "[ERROR] 이름은 5자 이하여야 합니다."라는 에러 메시지를 보여 준다.
- 자동차가 2대 이상이 아니라면, "[ERROR] 자동차는 2대 이상이어야 합니다."라는 에러 메시지를 보여 준다.

### 2. 시도할 횟수를 입력 받는다.

- 1 이상이 아니라면, "[ERROR] 시도할 횟수는 1회 이상이어야 합니다."라는 에러 메시지를 보여 준다.

### 3. 시도할 횟수만큼 경주를 진행하고 차수별 실행 결과를 저장한다.
