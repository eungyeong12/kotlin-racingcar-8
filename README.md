# 자동차 경주

## 기능 목록

### 1. 경주할 자동차 이름을 입력받는다.

- 이름은 쉼표 기준으로 구분한다.
- 이름이 비어 있을 경우, '자동차의 이름이 입력되지 않았습니다' 메시지를 던진다.
- 이름이 중복되는 경우, '자동차의 이름은 중복될 수 없습니다' 메시지를 던진다.

### 2. 시도할 횟수를 입력한다.

- 정수가 아니라면, '시도할 횟수는 정수여야 합니다' 메시지를 던진다.
- 양의 정수가 아니라면, '시도할 횟수는 1 이상이어야 합니다' 메시지를 던진다.

### 3. 횟수만큼 n대의 자동차를 전진시키거나 멈추게 한다.

- 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
- 차수별 실행 결과를 저장한다.

### 4. 차수별 실행 결과를 출력한다.

### 5. 최종 우승자를 출력한다.

- 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
